# Бранд източници

Редактируемият източник на OG банера. Публикува се само изнесеният PNG
(`public/brand/social/banner-social-preview-1200x630.png`), който
`src/layouts/Layout.astro` подава на `og:image`.

Файловете тук не влизат в `dist/`: идентичността на клуба не бива да стои
на предполагаем публичен адрес.
