# Бранд източници

Непубликуваните бранд източници:

- `brand-guide.pdf` — пълните насоки от бранд кита. [`../brand.md`](../brand.md)
  описва само това, което сайтът прилага, и сочи насам за останалото.
- `banner-social-preview-1200x630.svg` — редактируемият източник на OG банера.
  Публикува се само изнесеният PNG
  (`public/brand/social/banner-social-preview-1200x630.png`), който
  `src/layouts/Layout.astro` подава на `og:image`.

Файловете тук не влизат в `dist/`: идентичността на клуба не бива да стои
на предполагаем публичен адрес.

Когато организацията на клуба в GitHub съществува, китът се изнася там и
прозата тук сочи организацията вместо локалния PDF. Дотогава репото е
самостоятелно.
